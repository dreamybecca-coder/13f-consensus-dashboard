# 13F 机构共识看板

把分散、滞后的 13F 机构披露，整理成可以检查的持仓共识、集中度与季度变化。

**[打开实时看板](https://dreamybecca-coder.github.io/13f-consensus-dashboard/)**

## 它解决什么问题

单独看一份 13F，很容易停留在“某位投资人买了什么”。这个看板把 11 位精选 Manager 放在同一个可比较的结构里，帮助研究者进一步判断：

- 哪些证券被多家机构反复持有；
- 共识在不同季度是增强、减弱，还是发生分歧；
- 单个 Manager 的组合集中度与主要仓位如何变化；
- 哪些线索值得进入下一步公司、行业或投资逻辑研究。

看板同时保留 ARK 周度交易汇总，作为与季度 13F 分开的高频补充信源。

## 数据与方法边界

- 13F 数据来自 SEC EDGAR 官方信息表 XML，覆盖 2025 Q2 至 2026 Q2 五个季度。
- ARK 数据来自 arkfunds.io 对 ARK 官方每日披露的镜像汇总。
- 行业分类采用 GICS 口径。
- 13F 通常在季度结束后约 45 天披露，并且主要反映申报的美国多头持仓。
- 看板展示历史披露，不代表实时资金流向，不是买卖信号，也不构成投资建议。
